# Классификация iPhone и Android методом KNN

Учебный проект по дисциплине «Интеллектуальные системы и технологии» (задача № 1). Программа реализует алгоритм *k ближайших соседей* (KNN) для классификации предпочтений между iPhone и Android по двум признакам: бюджету и важности камеры.

Реализация использует только стандартную библиотеку Python.

## Структура проекта

```text
.
├── main.py       # Обучение, выбор k и прогноз
├── data.csv      # Данные для классификации
└── test_main.py  # Модульные тесты
```

## Требования

Python 3.8 или новее. Установка сторонних библиотек не требуется.

## Данные

Файл `data.csv` должен содержать ровно три столбца в указанном порядке:

| Столбец | Назначение | Допустимые значения |
| --- | --- | --- |
| `budget` | Бюджет на покупку смартфона | Положительное число, млн VND |
| `camera` | Важность качества камеры | Число от 1 до 5 |
| `phone` | Целевой класс | `iPhone` или `Android` |

Заголовок CSV:

```csv
budget,camera,phone
```

Для каждого класса необходимо не менее пяти записей. Столбец `phone` используется только как целевая метка и не участвует в вычислении расстояний.

**Примечание о данных:** исходный файл `data.csv` содержит 48 синтетических записей, созданных для проверки работы программы. Это не результаты реального опроса. Перед использованием проекта в отчёте необходимо собрать и подставить реальные данные, описав способ их получения.

## Запуск

Из каталога проекта выполните:

```bash
python main.py
```

Для прогноза с заданными параметрами:

```bash
python main.py --budget 22 --camera 5
```

Для использования другого CSV-файла:

```bash
python main.py --data path/to/data.csv
```

Параметры `--budget` и `--camera` по умолчанию равны `20` (млн VND) и `4` соответственно. На macOS или Linux при необходимости используйте `python3` вместо `python`.

## Метод

1. Программа читает CSV и проверяет структуру и допустимые значения.
2. Данные разделяются на обучающую (примерно 60%), валидационную (примерно 20%) и тестовую (примерно 20%) выборки с сохранением долей классов. Используется `seed=42`.
3. Параметры нормализации Min–Max вычисляются только по обучающей выборке, затем применяются ко всем остальным данным.
4. Расстояние между объектами рассчитывается по двум признакам (`budget`, `camera`) с помощью евклидовой метрики.
5. Класс определяется большинством голосов среди `k` ближайших соседей. При равенстве голосов выбирается класс ближайшего соседа из числа классов с равным количеством голосов.
6. На валидационной выборке сравниваются значения `k = 1, 3, 5, 7, 9`, не превышающие размер обучающей выборки. При одинаковой точности выбирается меньшее `k`.
7. Выбранная модель оценивается на тестовой выборке один раз, после чего выполняется прогноз для нового пользователя.

Программа выводит размеры выборок, точность на валидации для каждого `k`, выбранное значение `k`, точность на тесте и итоговый прогноз.

## Тестирование

```bash
python -m unittest -v
```

Тесты в `test_main.py` проверяют поиск ближайших соседей, голосование большинства, разрешение ничьей, нормализацию, обработку недопустимых значений `k` и использование ровно двух признаков.

## Отчёт и сдача

В отчёте по задаче № 1 необходимо указать способ сбора данных, распределение обязанностей в команде, применение парного программирования, результаты тестирования, таблицу точности для разных значений `k`, выбранное `k`, пример прогноза, результаты проверки кода (code review) и ограничения набора данных.

Исходный код необходимо разместить на GitHub и отправить ссылку преподавателю не позднее чем за 48 часов до занятия в соответствии с требованиями курса.

## Ограничения

Модель учитывает только бюджет и важность камеры. Другие факторы выбора смартфона не рассматриваются. Результаты на синтетических данных демонстрируют работу алгоритма, но не подтверждают его способность достоверно прогнозировать предпочтения реальных пользователей.
